# Guia Detalhado: Amazon EC2 API (FinOps)

## Visão Geral

O EC2 é tipicamente o maior gerador de custos na AWS. Monitorar instâncias, volumes EBS, snapshots, IPs elásticos e NAT Gateways é fundamental para FinOps.

| Atributo | Valor |
| :--- | :--- |
| **Endpoint** | `https://ec2.{region}.amazonaws.com/` |
| **Protocolo** | Query API (form-urlencoded) |
| **Service Name (IAM)** | `ec2` |
| **Versão da API** | `2016-11-15` |

---

## Ações da API

### 1. DescribeInstances

Lista todas as instâncias EC2 com detalhes completos.

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `InstanceId.N` | Array | Não | IDs de instâncias específicas. |
| `Filter.N` | Array | Não | Filtros (ex: `instance-state-name=running`, `tag:Environment=Production`). |
| `MaxResults` | Integer | Não | Número máximo de resultados (5-1000). |
| `NextToken` | String | Não | Token para paginação. |
| `DryRun` | Boolean | Não | Verifica permissões sem executar. |

#### Filtros Mais Úteis para FinOps

| Nome do Filtro | Descrição |
| :--- | :--- |
| `instance-state-name` | `running`, `stopped`, `terminated`. |
| `instance-type` | Tipo da instância (ex: `t3.micro`). |
| `tag:Key=Value` | Filtro por tag. |
| `platform` | `windows` ou vazio (Linux). |
| `tenancy` | `default`, `dedicated`, `host`. |
| `vpc-id` | ID da VPC. |

#### Exemplo de Requisição

```
Action=DescribeInstances
&Version=2016-11-15
&Filter.1.Name=instance-state-name
&Filter.1.Value.1=running
&MaxResults=100
```

---

### 2. DescribeVolumes

Lista todos os volumes EBS.

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `VolumeId.N` | Array | Não | IDs de volumes específicos. |
| `Filter.N` | Array | Não | Filtros (ex: `status=available` para volumes não anexados). |
| `MaxResults` | Integer | Não | Número máximo de resultados. |
| `NextToken` | String | Não | Token para paginação. |

#### Filtros Mais Úteis para FinOps

| Nome do Filtro | Descrição |
| :--- | :--- |
| `status` | `creating`, `available`, `in-use`, `deleting`, `deleted`, `error`. |
| `volume-type` | `gp2`, `gp3`, `io1`, `io2`, `st1`, `sc1`, `standard`. |
| `size` | Tamanho em GiB. |
| `attachment.status` | `attaching`, `attached`, `detaching`. |

#### Exemplo de Requisição (Volumes não anexados)

```
Action=DescribeVolumes
&Version=2016-11-15
&Filter.1.Name=status
&Filter.1.Value.1=available
```

### 3. DescribeSnapshots

Lista snapshots EBS.

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `SnapshotId.N` | Array | Não | IDs de snapshots específicos. |
| `Owner.N` | Array | Não | `self` (próprios), `amazon`, ou ID de conta. |
| `Filter.N` | Array | Não | Filtros. |
| `MaxResults` | Integer | Não | Número máximo de resultados. |
| `NextToken` | String | Não | Token para paginação. |

#### Exemplo de Requisição

```
Action=DescribeSnapshots
&Version=2016-11-15
&Owner.1=self
```

---

### 4. DescribeAddresses

Lista Elastic IPs. IPs não associados geram custo de $0.005/hora.

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `AllocationId.N` | Array | Não | IDs de alocação específicos. |
| `PublicIp.N` | Array | Não | IPs públicos específicos. |
| `Filter.N` | Array | Não | Filtros. |

#### Exemplo de Requisição

```
Action=DescribeAddresses
&Version=2016-11-15
```

---

### 5. DescribeNatGateways

Lista NAT Gateways. Recurso com custo significativo ($0.045/hora + dados processados).

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `NatGatewayId.N` | Array | Não | IDs de NAT Gateways específicos. |
| `Filter.N` | Array | Não | Filtros (ex: `state=available`, `vpc-id`). |
| `MaxResults` | Integer | Não | Número máximo de resultados. |
| `NextToken` | String | Não | Token para paginação. |

#### Exemplo de Requisição

```
Action=DescribeNatGateways
&Version=2016-11-15
&Filter.1.Name=state
&Filter.1.Value.1=available
```

---

### 6. DescribeReservedInstances

Lista as Reserved Instances ativas.

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `ReservedInstancesId.N` | Array | Não | IDs de RIs específicas. |
| `Filter.N` | Array | Não | Filtros (ex: `state=active`). |
| `OfferingClass` | String | Não | `standard` ou `convertible`. |
| `OfferingType` | String | Não | `Heavy Utilization`, `Medium Utilization`, `Light Utilization`, `No Upfront`, `Partial Upfront`, `All Upfront`. |

#### Exemplo de Requisição

```
Action=DescribeReservedInstances
&Version=2016-11-15
&Filter.1.Name=state
&Filter.1.Value.1=active
```

### 7. DescribeSpotPriceHistory

Retorna o histórico de preços de Spot Instances.

#### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição |
| :--- | :--- | :--- | :--- |
| `InstanceType.N` | Array | Não | Tipos de instância. |
| `ProductDescription.N` | Array | Não | `Linux/UNIX`, `Windows`, etc. |
| `AvailabilityZone` | String | Não | Zona de disponibilidade. |
| `StartTime` | Timestamp | Não | Início do período. |
| `EndTime` | Timestamp | Não | Fim do período. |
| `MaxResults` | Integer | Não | Número máximo de resultados. |
| `NextToken` | String | Não | Token para paginação. |

#### Exemplo de Requisição

```
Action=DescribeSpotPriceHistory
&Version=2016-11-15
&InstanceType.1=m5.large
&ProductDescription.1=Linux/UNIX
&StartTime=2026-02-22T00:00:00Z
&EndTime=2026-02-23T00:00:00Z
```
