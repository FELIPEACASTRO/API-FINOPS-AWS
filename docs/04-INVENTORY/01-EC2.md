# Guia Devastadoramente Detalhado: Amazon EC2 API (para FinOps)

## Visão Geral

Para FinOps, a API do EC2 é crucial para inventário, análise de estado e coleta de metadados que alimentam decisões de otimização. Embora a API seja vasta, algumas chamadas `Describe*` são particularmente importantes para entender o que você tem, onde está e como está configurado. Focaremos nas chamadas de leitura (`Describe*`) que fornecem a visibilidade necessária.

| Atributo | Valor |
| :--- | :--- |
| **Endpoint** | `https://ec2.{region}.amazonaws.com` |
| **Protocolo** | Query (GET/POST) |
| **Service Name (IAM)** | `ec2` |

---

## 1. DescribeInstances

Esta é a chamada mais importante para inventário. Ela retorna informações abrangentes sobre uma ou mais das suas instâncias EC2.

### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição Detalhada e Didática |
| :--- | :--- | :--- | :--- |
| `Filters` | Array de Objetos | Não | Filtra os resultados. Cada objeto tem `Name` e `Values` (um array de strings).<br>**Nomes de Filtro Úteis**: `instance-state-name` (`pending`, `running`, `shutting-down`, `terminated`, `stopping`, `stopped`), `instance-type`, `tag:<key>` (ex: `tag:Project`), `vpc-id`.<br>**Uso**: Essencial para focar. Use `instance-state-name: running` para ver apenas instâncias ativas. Use `tag:Project` para listar instâncias de um projeto específico. |
| `InstanceIds` | Array de Strings | Não | Uma lista de IDs de instâncias específicas para descrever. |
| `MaxResults` | Integer | Não | Número máximo de resultados por página. Útil para controlar o volume de dados. |
| `NextToken` | String | Não | Token para paginação, para obter a próxima página de resultados. |

### Exemplo de Requisição (Listar todas as instâncias T3 em execução)

```json
{
  "Filters": [
    {
      "Name": "instance-state-name",
      "Values": ["running"]
    },
    {
      "Name": "instance-type",
      "Values": ["t3.*"]
    }
  ]
}
```

## 2. DescribeVolumes

Retorna informações sobre seus volumes EBS. Crucial para identificar volumes não utilizados (desanexados) ou subutilizados.

### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição Detalhada e Didática |
| :--- | :--- | :--- | :--- |
| `Filters` | Array de Objetos | Não | Filtra os volumes.<br>**Nomes de Filtro Úteis**: `status` (`creating`, `available`, `in-use`, `deleting`, `deleted`, `error`), `volume-type` (`gp2`, `gp3`, `io1`, `io2`, `st1`, `sc1`, `standard`), `tag:<key>`.<br>**Uso**: **Fundamental para otimização**. Use `status: available` para encontrar volumes "órfãos" que estão gerando custo mas não estão anexados a nenhuma instância. |
| `VolumeIds` | Array de Strings | Não | IDs de volumes específicos. |
| `MaxResults` | Integer | Não | Número máximo de resultados. |
| `NextToken` | String | Não | Token para paginação. |

### Exemplo de Requisição (Encontrar volumes desanexados para possível exclusão)

```json
{
  "Filters": [
    {
      "Name": "status",
      "Values": ["available"]
    }
  ]
}
```

## 3. DescribeSnapshots

Retorna informações sobre seus snapshots de EBS. Snapshots antigos podem acumular custos significativos ao longo do tempo.

### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição Detalhada e Didática |
| :--- | :--- | :--- | :--- |
| `Filters` | Array de Objetos | Não | Filtra os snapshots.<br>**Nomes de Filtro Úteis**: `start-time` (para encontrar snapshots mais antigos que uma data), `tag:<key>`, `volume-id`. |
| `OwnerIds` | Array de Strings | Não | Use `["self"]` para listar apenas os snapshots que você criou. |
| `SnapshotIds` | Array de Strings | Não | IDs de snapshots específicos. |
| `MaxResults` | Integer | Não | Número máximo de resultados. |
| `NextToken` | String | Não | Token para paginação. |

### Exemplo de Requisição (Encontrar snapshots com mais de 1 ano)

```json
{
  "OwnerIds": ["self"],
  "Filters": [
    {
      "Name": "start-time",
      "Values": ["2025-02-23T00:00:00.000Z"] // Use uma data no passado
    }
  ]
}
```

## 4. DescribeAddresses

Retorna informações sobre seus Elastic IP addresses. IPs elásticos que não estão associados a uma instância em execução incorrem em custos.

### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição Detalhada e Didática |
| :--- | :--- | :--- | :--- |
| `Filters` | Array de Objetos | Não | Filtra os IPs.<br>**Nomes de Filtro Úteis**: `domain` (`vpc` ou `standard`), `instance-id` (para ver se está associado). Se o `instance-id` não existir na resposta, o IP não está associado. |
| `PublicIps` | Array de Strings | Não | IPs públicos específicos. |
| `AllocationIds` | Array de Strings | Não | IDs de alocação específicos. |

### Exemplo de Requisição (Listar todos os EIPs na VPC)

```json
{
  "Filters": [
    {
      "Name": "domain",
      "Values": ["vpc"]
    }
  ]
}
```

## 5. DescribeReservedInstances

Retorna informações sobre as Reserved Instances (RIs) que você possui. Essencial para rastrear seu inventário de compromissos.

### Parâmetros de Entrada

| Parâmetro | Tipo | Obrigatório | Descrição Detalhada e Didática |
| :--- | :--- | :--- | :--- |
| `Filters` | Array de Objetos | Não | Filtra as RIs.<br>**Nomes de Filtro Úteis**: `state` (`payment-pending`, `active`, `payment-failed`, `retired`), `instance-type`, `scope` (`Region` ou `Availability Zone`).<br>**Uso**: Use `state: active` para ver seus compromissos atuais. |
| `ReservedInstancesIds` | Array de Strings | Não | IDs de RIs específicas. |
| `OfferingClass` | String | Não | `standard` ou `convertible`. |

### Exemplo de Requisição (Listar todas as RIs ativas)

```json
{
  "Filters": [
    {
      "Name": "state",
      "Values": ["active"]
    }
  ]
}
```
